## Why the expected epidemic share is high

The pooled expected epidemic-hazard share is 28.1569% (20/20 seeds have post-own-KEY-5 exposure), against the proposed 10–14% band. The main direct drivers are outbreak infection hazard: attack rate from `R0 × density pressure`, then case fatality. The current class values in `LivingEconomyModel.Health.cs` are Fever R0/CFR 1.5/3%, Flux 2/8%, Pox 4/15%, and Plague 2/35%; Plague R0/CFR also come from the `PlagueR0`/`PlagueCFR` balance constants. The E5 runtime class mix is fixed at 55% Fever, 35% Flux, 0% Pox, 10% Plague (`E3ClassWeights`), documented in code as an E3 interpolation. Pox's 1,000-person endemic threshold is effectively absent in this natural cohort: no Pox deaths were attributed. Plague has the highest CFR; 27,846 epidemic deaths were attributed to active Plague and 28,423 remained unclassified by Pox/Plague, likely including Fever/Flux. The trace counts by active class, not expected hazard by class, so that split is an observed-death diagnostic, not an exact expected-hazard decomposition.

The natural cohort had 3,742 post-KEY-5 quarantine civilization-seasons but zero valid route-import attempts. Thus the draft MED-08 imported-outbreak gate (`1/2`) and separate imported-outbreak roll (`3/4`, corresponding to the catalogued ×0.75) had no observed route imports on which to act. The separate inter-settlement effect did run in the model (quarantined spread chance 2.5% versus 5%); it cannot be credited with proving the import effect. MED-07's draft 20% hospital epidemic-hazard reduction applied only where a hospital was actually staffed. These local reductions did not bring the cohort near the proposed share band.

## Calibration arithmetic (hypothesis only)

If all infected epidemic hazards were multiplied by a common Fief/E5 factor `k`, while non-epidemic hazards and outbreak incidence stayed fixed, the pooled share would become `kE / (N + kE)`, where the current share is `E / (N + E) = 0.281569`. Solving for a 12% target gives `k = 0.34794`. Factors of approximately **0.2835–0.4154** map the current pooled share to 10–14%. Applying `k=0.34794` to each existing seed-bootstrap ratio would project the 95% interval to approximately **11.15–12.73%**; the monotone transformation preserves inclusion of 12% under this simplified fixed-non-epidemic assumption.

This points to a roughly 65% reduction of the *effective infected epidemic mortality hazard* as an initial fit hypothesis. It does not establish which individual CFR should change: a single all-class Fief/E5 hazard scale would be a clean temporary diagnostic lever, while changing class CFRs separately would require expected per-class hazard exposure that the current trace does not report. Lowering R0 also changes attack incidence nonlinearly and should not be mixed into the first fit. Do not change MED-08 import values to repair this metric; no valid route imports occurred, and those values answer a separate import-control question.
