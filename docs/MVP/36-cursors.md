# 36 · Mouse pointers

The game draws its own mouse pointers: bone fill, a dark oxblood outline, gold accents (the diamonds and cuffs of the title and CTA plates) and a soft shadow. They are a little larger than the OS pointer. A setting turns them off.

## 1. Verdict

Good idea, with conditions. Strategy games (Civilization, Age of Empires, Anno, Total War) all ship themed pointers, so players expect one, and a mode-specific pointer tells you what a click will do (aim at a tile, grab the map, drop a project). The conditions, all met here:

- **Hardware cursor.** `Input.SetCustomMouseCursor` hands the image to the OS, so the pointer moves with no lag. Never draw the pointer as a sprite in the scene.
- **Reads on anything.** Light fill inside a dark outline works on bright parchment, dark panels and busy terrain.
- **Exact hotspot** (§3), on the visible tip or centre.
- **Only meaningful states.** Each image matches a mode the game already has. Shapes with no image (resize arrows, busy) keep the OS pointer.
- **An off switch.** Settings → "Game-styled mouse pointer" (saved as `themed_cursor` in `user://settings.cfg`), or `UiCursors.Enabled = false` for everyone.

**Era tint.** The gold accents (diamonds, cuffs, badge, hairline) take the viewer's age tint from `UiSkins` (§6), so the pointer matches the panel skin and changes when the age does. The red "no" sign keeps its colour.

Not done: no animated busy cursor (the game has no busy state).

## 2. States

| File | Godot shape | When the game shows it |
|---|---|---|
| `arrow` | `Arrow` | Default. |
| `hand` | `PointingHand` | Anything clickable that sets it: buttons, chips, cards, the research web. |
| `grab` | `Drag` | Panning the world map with the left button (`Game.Camera.cs`) or the research tree. |
| `drop` | `CanDrop` | Dragging a research project over a slot that accepts it. Godot picks this shape itself. |
| `ibeam` | `Ibeam` | Text fields: settlement rename, research search. |
| `forbidden` | `Forbidden` | Dragging a research project over a place it cannot go. Godot picks this shape itself. |
| `target` | `Cross` | Choosing a map tile: Beacon mode, decree targets (Found, Expedition, mine). |

## 3. Files, sizes and hotspots

`game/assets/ui/cursor/<file>.png` (40 × 40), `<file>@1.5x.png` (60 × 60), `<file>@2x.png` (80 × 80). They are generated by `tools/skin-gen/gen_cursors.py`:

    uv run --no-project --with numpy --with pillow python tools/skin-gen/gen_cursors.py [--preview sheet.png]

`--preview` draws every pointer at 2x on light, dark and noisy backgrounds, with the hotspot marked in red.

Hotspots, in 1x pixels from the top-left. The game multiplies them by the image's own scale (width ÷ 40):

| File | Hotspot | Point |
|---|---|---|
| `arrow` | (4, 3) | arrow tip |
| `hand` | (16, 3) | index fingertip |
| `grab`, `drop` | (19, 20) | middle of the fist |
| `ibeam`, `forbidden`, `target` | (20, 20) | centre |

The hotspots are listed in both `gen_cursors.py` (`HOTSPOTS`) and `game/Scripts/Ui/UiCursors.cs`. Change them in both places.

**Which size is used.** On macOS Godot sizes a custom cursor in points, so the game always uses the 1x set. On Retina screens it is upscaled, which is why the art uses bold shapes and no thin hairline-only detail. On Windows and Linux the cursor is sized in physical pixels, so the game picks 1x, 1.5x or 2x from the screen's scale. Godot rejects images larger than 256 × 256.

## 4. Swapping in hand-made art

Drop PNGs over the generated ones with the **same file names and sizes**, keeping the tip or centre exactly at the hotspot in §3. Use a transparent background, a dark outline about 2 px at 1x, and no glow wider than about 4 px. A set with only the 1x files works: the loader falls back to `<file>.png` when an @-size is missing. Then open the project in Godot once (or run `Godot --headless --path game --import`). To leave a state on the OS pointer, delete its files.

Prompt for painted versions: "a game mouse cursor, [arrow pointer | pointing gauntlet hand | closed fist | text I-beam | prohibition sign | targeting reticle], cream bone colour with a thick dark brown outline, small gold diamond ornament, flat 2D game UI, no text, plain contrasting background". Tell me the background colour and I key it to transparent.

## 5. Era tint files

Each pointer with gold also has `<file>_accent.png` / `@1.5x` / `@2x` (same size as the pointer; `forbidden` has none). RGB is the gold's own colour at that pixel, alpha is how much of the pixel is gold. The generator makes them by rendering the pointer with the gold as white and as black. The game then does `out = base + mask * (tint * luma(old) / luma(gold) - old)`, which keeps the light-to-dark shading and the soft edges. If a mask is missing (hand-made art) that pointer keeps its own colours.

`gen_cursors.py --preview-eras sheet.png` draws four pointers in all ten age tints on dark and light strips.

## 6. Code

`game/Scripts/Ui/UiCursors.cs`. `UiCursors.Apply()` also re-runs when `UiSkin.ShownEraChanged` fires (an age change or the Settings skin override). It runs at start-up (`Startup.cs`, and `Game.Hud.cs` for runs that skip the title) and when the setting changes. It passes Godot a CPU `Image`, not the texture, so nothing leaks at quit. Headless runs keep the OS pointer.
